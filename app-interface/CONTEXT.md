# Context of this directory

This directory is main directory for source code of Angular Frontend.

## Rules

Rules on working in this directory is avaliable in rules files folder [./app-interface/.agent/rules](./app-interface/.agent/rules). 

## Skills 

Skill to use while working in this directory is avaliable in skills files folder [./app-interface/.agent/skills](./app-interface/.agent/skills). 

## Naming Convention

Please use this naming convention for front end project.

### Format:

`feature-name-[component].component.ts`
 
### Example: 

`product-review-analysis-button.component.ts`
